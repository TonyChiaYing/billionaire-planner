## 交付方式備忘
- 雲端編譯：推 main → GitHub Actions → `build` 分支有 .app zip 與各測試 log
- Mac 交付：zip（保留執行權限）→ 寫入 Planner → Finder「打開」解壓 → 舊版移垃圾桶（先封存到 _Archive）
- 版本：VERSION 四段；MARKETING_VERSION 三段；CURRENT_PROJECT_VERSION 四段
