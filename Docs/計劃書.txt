
🚀 億萬富豪級個人計畫 App (V1 MVP) 開發計劃書


📌 產品定位與核心哲學

這是一款融合了巴菲特（聚焦減法）、馬斯克（時間顆粒度）、雷·達利奧（演算法復盤）與比爾蓋茲（深度思考）思維模型的個人增長與資產追蹤系統。
• 目標：透過數位防禦，保護使用者的專注力（時間）與生產力（資產），阻絕無效雜務。
• 核心痛點：現代人計畫過多（目標發散）、執行太粗（缺乏時間塊管理）、復盤無效（沒有系統化更新）。

🛠️ 第一階段：核心功能模組 (v1 Scope)


1. 【巴菲特模組】5/25 焦點排除清單 (Focus Shield)

• 功能描述：強迫使用者列出 25 個目標，但只能啟用 5 個。
• AI 實作邏輯：
	• 提供一個輸入列表，上限 25 項。
	• 使用者選定 5 個「核心衝刺目標」後，系統自動鎖定其餘 20 個項目。
	• 防禦機制：在 Top 5 項目被標記為「已完成」之前，其餘 20 個項目在主介面上呈現「灰色不可點擊/隱藏」狀態，嚴禁使用者為其建立日程，並跳出警告提示：「這是你的精力殺手！」

2. 【馬斯克模組】5分鐘/15分鐘 顆粒度時間塊 (Hyper-Chronos)

• 功能描述：打破傳統「小時」排程，改用高效時間區塊（建議以 15 分鐘為 V1 基礎單位，可切換 5 分鐘極限模式）。
• AI 實作邏輯：
	• 大腦傾倒區 (Brain Dump)：清晨允許使用者快速輸入今日的「槓桿任務（High-Leverage Tasks）」。
	• 時間拖拉網格 (Grid Time-Blocking)：提供 06:00 - 24:00 的視覺化網格，以 15 分鐘為一格，使用者可將任務直接拖放至網格中。
	• 任務脈絡聚合 (Context Batching)：支援幫時間塊貼上標籤（例如：#財務決策、#深度工作、#緩衝/雜務），且系統會提醒相同的標籤應儘量黏合在一起，減少大腦切換成本。

3. 【達利奧模組】痛楚 + 反思 = 進步 演算法日誌 (Principles Log)

• 功能描述：當項目遭遇失敗或虧損時，不只是記錄心情，而是升級自己的「人生運作原則」。
• AI 實作邏輯：
	• 建立一個特殊的「日落三問/錯誤診斷」表單。
	• 欄位包含：遭遇問題/痛點 ➡️ 根本原因診斷（人或系統流程？） ➡️ 得出的核心原則（Actionable Principle）。
	• 原則資料庫：每次輸入後，該「原則」會被存入專屬資料庫，並在未來的相關任務啟動時，作為彈出式提示（Prompt）來指導使用者。

4. 【蓋茲模組】虛擬「思考週」數位排毒模式 (Think Week Mode)

• 功能描述：模擬比爾蓋茲的封閉閱讀與思考狀態。
• AI 實作邏輯：
	• 一鍵啟動「思考週/思考日」計時器。
	• 啟動後，App 主介面進入全黑/極簡模式，完全隱藏所有日常待辦事項與瑣碎通知。
	• 畫面僅顯示兩個核心區塊：【當前閱讀/研究主題】 與 【黃色法規紙（數位白板草稿區）】，引導使用者進行跨領域深度合成思考。

🎨 2. UI/UX 視覺與互動規範

• 設計風格：極簡、高對比、暗黑模式優先（Deep Cyber Black / Obsidian Grey）。視覺上給人一種「儀表板/控制台」的冷靜感。
• 主色調：
	• #00FF66（資產/專注綠：代表高價值任務、啟用中的 Top 5）。
	• #FF3B30（警示紅：代表問題日誌、精力殺手提醒）。
	• #8E8E93（防禦灰：代表被鎖定的其餘 20 個非核心目標）。
• 關鍵操作體驗：無縫的拖拉任務、嚴格的無效點擊攔截（當使用者試圖點擊被鎖定的目標時，觸發微震動與醒目提示）。

📐 3. 技術棧建議 (Tech Stack for V1)

你可以根據你的技術背景，請 AI 選擇以下其中一套方案來生成代碼：
• 方案 A (全網頁 Web 優先 - 推薦 Claude 直接生成)：
	• 前端：React.js / Next.js 或 Vue.js (搭配 Tailwind CSS 實現極簡設計)。
	• 狀態管理：Zustand 或 LocalStorage（V1 先不接複雜後端，數據直接存瀏覽器）。
• 方案 B (行動端跨平台 App)：
	• Flutter 或 React Native，確保在手機上有最好的「5分鐘時間塊」操作流暢度。

🏁 4. V1 MVP 實作衝刺三步驟 (AI Prompt 指令)

當你將這份計劃書餵給 AI 後，請依序輸入以下指令讓它開始寫代碼：
• 步驟一（架構與巴菲特模組）：「請根據上述開發計劃書，先使用 React + Tailwind CSS 幫我寫出 App 的基礎佈局，並完整實作【巴菲特 5/25 焦點排除清單】的功能，包含目標輸入、勾選前 5 個、以及鎖定其餘 20 個項目的邏輯與視覺效果。」
• 步驟二（馬斯克與達利奧模組）：「接著，請在同一個專案中，實作【馬斯克 15 分鐘時間塊網格】與【達利奧問題診斷日誌】。時間塊需要有大腦傾倒區與時間軸排程；日誌需要能儲存原則並顯示在清單中。」
• 步驟三（整合與優化）：「最後，請加上【蓋茲思考週模式】的一鍵切換開關，並確保整體的暗黑極簡 UI 風格一致，包含 LocalStorage 的資料儲存功能，讓我可以直接運行動態程式碼。」
